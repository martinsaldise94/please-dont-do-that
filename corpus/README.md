# PDTD Corpus

Labeled set of frontend pages used to **calibrate** the scorer, feed the
**tests** (golden files), and showcase how interchangeable AI landing pages are.

A detector is only as good as its ground truth. This corpus has **two classes**
so PDTD can prove it tells them apart:

- `generic/` — landing pages **generated by AI tools** (Claude, ChatGPT, v0,
  Lovable, Bolt, Cursor…). These should score **high AI Smell / low Business
  Specificity**.
- `specific/` — **real, business-specific** pages (or AI pages built from a very
  detailed brief). These should score **low AI Smell / high Business
  Specificity**.

Both classes cover **English and Spanish** content.

## Layout

```
corpus/
├── _templates/meta.json        # copy this for every new example
├── generic/
│   └── <industry>/
│       └── <tool>-<lang>-<nn>/  # e.g. claude-en-01
│           ├── index.html       # self-contained HTML (CSS inlined)
│           └── meta.json
└── specific/
    └── <industry>/
        └── <slug>-<lang>/       # e.g. lopez-physio-es
            ├── index.html
            └── meta.json
```

- **First level = class** (`generic` / `specific`) — the calibration axis.
- **Second level = industry** (see slugs below).
- **Language and source tool** live in the folder name and in `meta.json`.

## Industry slugs

`clinics`, `beauty-wellness`, `ecommerce`, `local-retail`, `restaurants`,
`fitness-gym`, `professional-services`, `home-services`, `agencies-portfolio`,
`education`, `saas-startup`.

> `saas-startup` is the single most AI-templated category — keep it well stocked.

## Each example = one folder with two files

1. `index.html` — the page exactly as produced, with the CSS **inside** the HTML
   so it is self-contained and easy to parse. (JSX + Tailwind examples are also
   welcome — set `format` accordingly and add the source files.)
2. `meta.json` — the label. Copy `_templates/meta.json` and fill it in.

### `meta.json` fields

| Field | Meaning |
|-------|---------|
| `id` | `"<industry>/<folder-name>"`, unique |
| `class` | `"generic"` or `"specific"` |
| `industry` | one of the slugs above |
| `language` | `"en"` or `"es"` |
| `format` | `"html"`, `"jsx"`, … |
| `source.type` | `"ai"` or `"real"` |
| `source.tool` | AI tool name (when `type` is `"ai"`) |
| `source.url` | original URL (when `type` is `"real"`) |
| `source.date` | capture / generation date (`YYYY-MM-DD`) |
| `source.prompt` | the exact prompt used (AI examples) |
| `expectedScores` | `[min, max]` ranges the scorer must land in |
| `tags` | structural/content patterns present |
| `notes` | anything worth remembering |

### Example — AI generated (generic)

```json
{
  "id": "clinics/claude-en-01",
  "class": "generic",
  "industry": "clinics",
  "language": "en",
  "format": "html",
  "source": {
    "type": "ai",
    "tool": "Claude",
    "model": "",
    "date": "2026-06-16",
    "prompt": "Create a landing page for a physiotherapy clinic."
  },
  "expectedScores": { "aiSmell": [70, 100], "businessSpecificity": [0, 30] },
  "tags": ["hero", "feature-cards", "testimonials", "pricing", "cta"],
  "notes": ""
}
```

### Example — real / specific

```json
{
  "id": "clinics/lopez-physio-es",
  "class": "specific",
  "industry": "clinics",
  "language": "es",
  "format": "html",
  "source": {
    "type": "real",
    "url": "https://example.com",
    "date": "2026-06-16"
  },
  "expectedScores": { "aiSmell": [0, 30], "businessSpecificity": [70, 100] },
  "tags": ["real-address", "named-staff", "specific-services"],
  "notes": "Specific city, named practitioners, concrete prices."
}
```
